# Grow with Benedict — Run in Codespaces

## 1. Upload this whole folder to your GitHub repo
Include the `assets` folder (especially `assets/icon.png`).

## 2. Open Codespaces → Terminal

```bash
npm install
npx expo start --tunnel
```

## 3. On your phone
- Install **Expo Go**
- Scan the QR code, or paste the `exp://` URL

## Icon
- `assets/icon.png` = app icon (1024×1024, gold GB on navy)
- Splash and Android adaptive icons are included

## Optional: real accounts
Edit `src/lib/supabase.ts` and put your Supabase URL + anon key.
